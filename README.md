## Scenario summary

Ecommerce Company GmbH is a mid-size German online retailer running a real-time product recommendation engine powered by first-party cookie data and purchase history. Their analytics and personalisation stack includes a US-based vendor (DataPulse Inc.), creating an international transfer question under Chapter V GDPR. The scenario is rich for GDPR analysis because it simultaneously triggers ePrivacy consent rules, legitimate interests assessment tension, and potential DPIA requirements.s
